# DermaIQ

Premium AI-powered skincare analyzer built with React Native and Expo.

## Stack

- Expo
- Expo Router
- TypeScript

## Structure

- `app/` route screens and navigation
- `components/` reusable UI primitives
- `lib/` theme tokens, mock data, and lightweight app state

## Screens

- Onboarding
- Home
- Scan
- Result
- History
- Profile

## Run

```bash
npm install
npm start
```
